# على الملعب — دليل التنس في الرياض

دليل عربي باتجاه RTL لـ١٥ ملعبًا ومنشأة، بتصميم متجاوب وأيقونات SVG محلية. يعمل دون مكتبات أو خطوط أو خدمات خارجية.

## التشغيل

افتح `index.html` مباشرة، أو قدّم هذا المجلد بأي خادم ملفات ثابتة. انشر ملفات المجلد معًا؛ تحتاج الصفحة إلى `styles.css` و`app.js` و`courts-data.js`.

## تجربة الاستخدام

- بحث عربي يتجاهل التشكيل واختلافات الهمزة، ويشمل الاسم والمنطقة وطريقة الحجز.
- تصفية بالأسعار، وروابط المواقع المشاركة، وطريقة الحجز، والمحفوظة.
- ترتيب أبجدي أو بسعر الساعة الصريح؛ الأسعار غير محددة المدة والحجوزات الأطول تأتي في النهاية.
- حفظ الملاعب على الجهاز، مع بديل مؤقت للجلسة إذا تعذّر التخزين المحلي.
- جداول أسعار قابلة للتوسيع، وروابط واضحة للحجز أو الموقع أو التطبيق أو التواصل.
- تنقل بلوحة المفاتيح، وتسميات للأزرار، وحالات خالية، واحترام تقليل الحركة.

## تحديث البيانات

`courts.json` هو المصدر المعتمد القابل للتحرير. `source-records.json` نسخة محفوظة من البيانات الأصلية للمراجعة، وليس مصدر العرض.

بعد تعديل `courts.json`، شغّل:

```sh
python3 build-data.py
```

هذا يولّد `courts-data.js` لتعمل الصفحة حتى عند فتحها مباشرة دون خادم. لا تعدّل الملف المولّد يدويًا.

مخطط البيانات الجديد يفصل الموقع ودرجة دقته، وقنوات الحجز، وجهات التواصل، والأسعار ومددها، وملاحظات المصدر. `null` يعني أن القيمة غير مسجّلة. مدد الأسعار بالدقائق، والأرقام بالصيغة الدولية حين تكون بنيتها مقبولة. قبول البنية لا يؤكد ملكية الرقم أو تشغيله.

## المراجعة

انظر `DATA-REVIEW.md` لمراجعة السجلات الـ١٥ وحدود التحقق. شغّل فحوص الحفاظ على البيانات الأصلية:

```sh
python3 verify-data.py
node --check app.js
```

فحص المقارنة مصمم لنسخة التنظيف هذه؛ إذا تغيّرت البيانات لاحقًا بمعلومات مؤكدة، حدّث توقعاته بما يناسبها.

لم تُنشر هذه التعديلات على موقع خارجي، ولم تُجرَ حجوزات أو اتصالات. المصادر والأسعار محفوظة من الدليل الأصلي ولم تُحدَّث ميدانيًا.
