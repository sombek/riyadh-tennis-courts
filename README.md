# مرجع ملاعب التنس في الرياض

صفحة عربية ثابتة ومتجاوبة تجمع 14 ملعبًا ومنشأة، مع البحث والتصفية وروابط الحجز والمواقع والأسعار المتوفرة.

## التشغيل
افتح `index.html` في المتصفح؛ لا تحتاج تثبيت أي مكتبات.

## البيانات
`courts.json` نسخة قابلة للتنزيل من البيانات المضمنة في `index.html`. عند التعديل حدّث النسختين معًا. روابط البحث ليست دبابيس مؤكدة، والأسعار والأرقام من ملاحظات المستخدم. لا يتم إجراء حجوزات أو إرسال رسائل تلقائيًا.

## النشر
GitHub Pages من الفرع main ومجلد الجذر.
